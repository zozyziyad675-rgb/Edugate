Q1. Evaluate L\{f(t)\} where f(t) = \begin{cases} 0, & 0 \le t < 3 \\ 2, & t \ge 3 \end{cases}.

A) \dfrac{2e^{-3s}}{s}, \quad s > 0
B) \dfrac{2e^{3s}}{s}, \quad s > 0
C) \dfrac{e^{-3s}}{s}, \quad s > 0
D) \dfrac{2}{s}, \quad s > 0

Answer: A) \dfrac{2e^{-3s}}{s}, \quad s > 0

---

Q2. What is the definition of the unit step function u(t)?

A) u(t) = \begin{cases} 1, & t < 0 \\ 0, & t \ge 0 \end{cases}
B) u(t) = \begin{cases} 0, & t < 0 \\ 1, & t \ge 0 \end{cases}
C) u(t) = \begin{cases} 0, & t \le 0 \\ 1, & t > 0 \end{cases}
D) u(t) = 1 for all t

Answer: B) u(t) = \begin{cases} 0, & t < 0 \\ 1, & t \ge 0 \end{cases}

Q3. What is the Laplace transform of the unit step function u(t)?

A) \dfrac{1}{s}, \quad s > 0
B) \dfrac{1}{s^2}, \quad s > 0
C) e^{-s}
D) 1

Answer: A) \dfrac{1}{s}, \quad s > 0

Q4. What is the Laplace transform of the shifted unit step function u(t-a)?

A) \dfrac{e^{as}}{s}
B) \dfrac{e^{-as}}{s}
C) \dfrac{1}{s-a}
D) e^{-as}

Answer: B) \dfrac{e^{-as}}{s}

---

Q5. When a function f(t) defined for t \ge 0 is multiplied by u(t-a), what happens to the graph?

A) The portion of f for t \ge a is turned off
B) The portion of f for 0 \le t < a is turned off
C) The entire graph of f is shifted by a
D) The entire graph of f is turned off

Answer: B) The portion of f for 0 \le t < a is turned off

Q6. A piecewise-defined function of the type f(t) = \begin{cases} g(t), & 0 \le t < a \\ h(t), & t \ge a \end{cases} can be written in compact form as:

A) f(t) = g(t) + (h(t) - g(t))u(t-a)
B) f(t) = g(t) - (h(t) + g(t))u(t-a)
C) f(t) = h(t) + (g(t) - h(t))u(t-a)
D) f(t) = g(t)u(t-a) + h(t)

Answer: A) f(t) = g(t) + (h(t) - g(t))u(t-a)

Q11. Express f(t) = \begin{cases} t^2, & 0 \le t < 2 \\ 4t, & t \ge 2 \end{cases} in terms of the unit step function.

A) f(t) = t^2 + (4t - t^2)u(t-2)

Q15. State the theorem for the Laplace transform of integrals.
A) If L\{f(t)\} = F(s), then L\left\{\int_0^t f(u)\,du\right\} = sF(s)
B) If L\{f(t)\} = F(s), then L\left\{\int_0^t f(u)\,du\right\} = \dfrac{F(s)}{s}
C) If L\{f(t)\} = F(s), then L\left\{\int_0^t f(u)\,du\right\} = \dfrac{F(s)}{s^2}
D) If L\{f(t)\} = F(s), then L\left\{\int_0^t f(u)\,du\right\} = F(s) - f(0)

Answer: B) If L\{f(t)\} = F(s), then L\left\{\int_0^t f(u)\,du\right\} = \dfrac{F(s)}{s}
