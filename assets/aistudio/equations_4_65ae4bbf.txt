Q1. What is the inverse Laplace transform of F(s) = \dfrac{3}{s^4}?

Q4. State the linear property of the inverse Laplace transform.

A) L^{-1}\{c_1F_1(s) + c_2F_2(s)\} = c_1L^{-1}\{F_1(s)\} \cdot c_2L^{-1}\{F_2(s)\}
B) L^{-1}\{c_1F_1(s) + c_2F_2(s)\} = c_1L^{-1}\{F_1(s)\} + c_2L^{-1}\{F_2(s)\}
C) L^{-1}\{c_1F_1(s) + c_2F_2(s)\} = L^{-1}\{F_1(s)\} + L^{-1}\{F_2(s)\}
D) L^{-1}\{c_1F_1(s) + c_2F_2(s)\} = \dfrac{c_1}{c_2}L^{-1}\{F_1(s)\}

Answer: B) L^{-1}\{c_1F_1(s) + c_2F_2(s)\} = c_1L^{-1}\{F_1(s)\} + c_2L^{-1}\{F_2(s)\}

Q6. Find L^{-1}\left\{3 + 2e^{-3s} + \dfrac{e^{-3s}}{s}\right\}.

A) 3\delta(t) + 2\delta(t-3) + u(t-3)

C) 3\delta(t) + 2u(t-3) + \delta(t-3)
D) 3\delta(t) + 2\delta(t+3) + u(t+3)

Answer: A) 3\delta(t) + 2\delta(t-3) + u(t-3)

Q7. State the First Shifting Property for the inverse Laplace transform.

A) If L^{-1}\{F(s)\} = f(t), then L^{-1}\{F(s-a)\} = e^{-at}f(t)
B) If L^{-1}\{F(s)\} = f(t), then L^{-1}\{F(s-a)\} = e^{at}f(t)
C) If L^{-1}\{F(s)\} = f(t), then L^{-1}\{F(s+a)\} = e^{at}f(t)
D) If L^{-1}\{F(s)\} = f(t), then L^{-1}\{F(s-a)\} = e^{t}f(t-a)

Answer: B) If L^{-1}\{F(s)\} = f(t), then L^{-1}\{F(s-a)\} = e^{at}f(t)
