Based on the fourth PDF lecture on Boolean Algebra Rules – Part 2, here are 20 multiple-choice questions.

1. According to De Morgan's Law, the complement of the function F = (A + B + C + D) is:
A) A' + B' + C' + D'
B) A' · B' · C' · D'
C) A · B · C · D
D) (A + B + C + D)'
Correct Answer: B) A' · B' · C' · D'

2. According to De Morgan's Law, the complement of the function F = (A · B · C · D) is:
A) A' · B' · C' · D'
B) A' + B' + C' + D'
C) A + B + C + D
D) (A · B · C · D)'
Correct Answer: B) A' + B' + C' + D'

3. When finding the complement of F₁ = x'y'z' + x'y'z, what is the first step using De Morgan's Law?
A) (x'y'z')' · (x'y'z)'
B) (x'y'z')' + (x'y'z)'
C) (x + y + z) · (x + y + z')
D) (x' + y' + z') · (x' + y' + z)
Correct Answer: A) (x'y'z')' · (x'y'z)'

4. In the simplification of the complement of F₂ = x(y'z' + yz), the term (y'z' + yz)' expands to:
A) (y + z) · (y' + z')
B) (y' + z') · (y + z)
C) (y + z') · (y' + z)
D) (y' + z) · (y + z')
Correct Answer: A) (y + z) · (y' + z')

5. What is the canonical form called when a function is expressed as a sum of minterms?
A) Product of Maxterms
B) Sum of Minterms
C) Canonical Product
D) Standard Sum
Correct Answer: B) Sum of Minterms

6. What is the canonical form called when a function is expressed as a product of maxterms?
A) Sum of Minterms
B) Product of Maxterms
C) Canonical Sum
D) Standard Product
Correct Answer: B) Product of Maxterms

7. For a 3-variable function, how many possible minterms are there?
A) 3
B) 6
C) 8
D) 16
Correct Answer: C) 8

8. Which symbol is used to denote the sum of minterms?
A) Π
B) Σ
C) ⊕
D) ∫
Correct Answer: B) Σ

9. Which symbol is used to denote the product of maxterms?
A) Σ
B) Π
C) ⊕
D) ∫
Correct Answer: B) Π

10. In the expression F = Σ(1, 4, 5, 6, 7), what does the number 1 represent?
A) A maxterm
B) A minterm
C) A variable
D) A constant
Correct Answer: B) A minterm

11. If F = Σ(1, 4, 5, 6, 7) for a 3-variable function, what are the corresponding maxterms?
A) Π(0, 2, 3)
B) Π(1, 4, 5, 6, 7)
C) Π(0, 1, 2, 3)
D) Π(2, 3, 4, 5)
Correct Answer: A) Π(0, 2, 3)

12. To express the function F = A + B'C in a sum of minterms, what should be done first?
A) Find the truth table
B) Find the complement
C) Simplify the function
D) Factor the function
Correct Answer: A) Find the truth table

13. In the truth table for F = A + B'C, which minterm corresponds to A=0, B=1, C=1?
A) m₀
B) m₃
C) m₅
D) m₇
Correct Answer: B) m₃

14. The minterm m₅ for a 3-variable function (A, B, C) corresponds to which combination?
A) A=0, B=0, C=0
B) A=1, B=0, C=1
C) A=1, B=1, C=0
D) A=0, B=1, C=0
Correct Answer: B) A=1, B=0, C=1

15. The maxterm M₀ for a 3-variable function (A, B, C) is expressed as:
A) A + B + C
B) A' + B' + C'
C) A · B · C
D) A' · B' · C'
Correct Answer: A) A + B + C

16. The minterm m₇ for a 3-variable function (A, B, C) is expressed as:
A) A'B'C'
B) A'BC
C) ABC
D) AB'C
Correct Answer: C) ABC

17. When converting F = xy + x'z to a sum of minterms using equations, the term xy is expanded by multiplying with:
A) (z + z')
B) (x + x')
C) (y + y')
D) (z · z')
Correct Answer: A) (z + z')

18. In the expansion of F = xy + x'z, the term x'z is expanded to:
A) x'y'z + x'yz
B) x'y'z' + x'yz'
C) x'yz + x'yz'
D) x'yz' + x'y'z
Correct Answer: A) x'y'z + x'yz

19. If F = Σ(1, 3, 6, 7), what is the corresponding product of maxterms?
A) Π(0, 2, 4, 5)
B) Π(1, 3, 6, 7)
C) Π(0, 1, 2, 3)
D) Π(4, 5, 6, 7)
Correct Answer: A) Π(0, 2, 4, 5)

20. The complement of the function F = (BC' + A'D)(AB' + CD') is found by:
A) Applying De Morgan's Law to the entire expression and then simplifying
B) Finding the truth table and inverting the output
C) Multiplying all terms directly
D) Adding all terms directly
Correct Answer: A) Applying De Morgan's Law to the entire expression and then simplifying
