Here are 20 multiple-choice questions based on Lecture 07 (Determinants and Square Systems – Cramer's Rule).

Q1. According to Theorem 1, which of the following is equivalent to "A is nonsingular"?
A) \det(A) = 0
B) \det(A) \neq 0
C) Ax = 0 has infinitely many solutions
D) Ax = b has no solution for some b
Answer: B) \det(A) \neq 0

Q2. If A is an n \times n matrix and \det(A) \neq 0, then the system Ax = b:
A) has no solution
B) has infinitely many solutions
C) has a unique solution x = A^{-1}b
D) has exactly two solutions
Answer: C) has a unique solution x = A^{-1}b

Q3. If A is nonsingular, the homogeneous system Ax = 0 has:
A) infinitely many solutions
B) no solution
C) only the trivial solution x = 0
D) exactly two solutions
Answer: C) only the trivial solution x = 0

Q4. In Example 1, the system with a unique solution is identified by checking:
A) whether the coefficient matrix is symmetric
B) whether the determinant of the coefficient matrix is nonzero
C) the number of equations
D) the number of unknowns
Answer: B) whether the determinant of the coefficient matrix is nonzero

Q5. If \det(A) = 0 for a square system Ax = b, then the system:
A) always has a unique solution
B) either has no solution or infinitely many solutions
C) always has infinitely many solutions
D) always has no solution
Answer: B) either has no solution or infinitely many solutions

Q6. Cramer's Rule applies only when the coefficient matrix A is:
A) singular
B) nonsingular (\det(A) \neq 0)
C) symmetric
D) triangular
Answer: B) nonsingular (\det(A) \neq 0)

Q7. In Cramer's Rule, the matrix A_k is obtained by:
A) deleting the k-th row of A
B) replacing the k-th column of A with the constant vector b
C) replacing the k-th row of A with b
D) multiplying the k-th column by b
Answer: B) replacing the k-th column of A with the constant vector b

Q8. According to Cramer's Rule, the solution component x_k is given by:
A) x_k = \det(A_k) \cdot \det(A)
B) x_k = \frac{\det(A_k)}{\det(A)}
C) x_k = \frac{\det(A)}{\det(A_k)}
D) x_k = \det(A_k) + \det(A)
Answer: B) x_k = \frac{\det(A_k)}{\det(A)}

Q9. Cramer's Rule is derived from the formula:
A) x = A b
B) x = A^{-1}b = \frac{1}{\det(A)} \text{adj}(A)b
C) x = A^T b
D) x = \det(A) \cdot b
Answer: B) x = A^{-1}b = \frac{1}{\det(A)} \text{adj}(A)b

Q10. For the system 4x_1 - 2x_2 = 10, 3x_1 - 5x_2 = 11, the determinant |A| is:
A) -14
B) 14
C) -26
D) 26
Answer: A) -14 (since 4(-5) - 3(-2) = -20 + 6 = -14)

Q11. For the system in Q10, Cramer's Rule gives x_1 as:
A) -2
B) 2
C) 1
D) -1
Answer: B) 2

Q12. For the system in Q10, Cramer's Rule gives x_2 as:
A) 2
B) -1
C) 1
D) -2
Answer: B) -1

Q13. For the 3 \times 3 system x_1 + 2x_2 + x_3 = 5, 2x_1 + 2x_2 + x_3 = 6, x_1 + 2x_2 + 3x_3 = 9, the solution is:
A) x_1 = 1, x_2 = 1, x_3 = 2
B) x_1 = 2, x_2 = 1, x_3 = 1
C) x_1 = 1, x_2 = 2, x_3 = 1
D) x_1 = 2, x_2 = 2, x_3 = 2
Answer: A) x_1 = 1, x_2 = 1, x_3 = 2

Q14. In Example 4, the determinant of the coefficient matrix is \Delta = 2. The value of \alpha = \det(A_1) is:
A) 1
B) -1
C) 3
D) 2
Answer: A) 1

Q15. In Example 4, the value of \beta = \det(A_2) is:
A) 1
B) -1
C) 3
D) 2
Answer: B) -1

Q16. In Example 4, the solution component x_3 is:
A) \frac{1}{2}
B) -\frac{1}{2}
C) \frac{3}{2}
D) 3
Answer: C) \frac{3}{2}

Q17. The solution of Example 4 obtained via Cramer's Rule is:
A) x_1 = \frac{1}{2}, x_2 = -\frac{1}{2}, x_3 = \frac{3}{2}
B) x_1 = -\frac{1}{2}, x_2 = \frac{1}{2}, x_3 = \frac{3}{2}
C) x_1 = \frac{1}{2}, x_2 = \frac{1}{2}, x_3 = -\frac{3}{2}
D) x_1 = 1, x_2 = -1, x_3 = 3
Answer: A) x_1 = \frac{1}{2}, x_2 = -\frac{1}{2}, x_3 = \frac{3}{2}

Q18. Which method(s) can be used to solve a square system with a nonsingular coefficient matrix?
A) Gauss-Jordan elimination only
B) Inverse method only
C) Cramer's Rule only
D) Gauss-Jordan, inverse method, and Cramer's Rule
Answer: D) Gauss-Jordan, inverse method, and Cramer's Rule

Q19. If \det(A) = 0 for a square coefficient matrix, which method is still useful to determine the solution type (infinite or none)?
A) Cramer's Rule
B) Inverse method
C) Elimination method (Gauss-Jordan)
D) Adjoint method
Answer: C) Elimination method (Gauss-Jordan)

Q20. Cramer's Rule for an n \times n system requires computing:
A) n determinants
B) n+1 determinants
C) n^2 determinants
D) only one determinant
Answer: B) n+1 determinants (one for A and one for each A_k)
