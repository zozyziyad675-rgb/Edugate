1. Implementing Functions using Gates

In digital logic, we don't always have every type of gate available. Sometimes, you are restricted to using only specific gates (like only AND & NOT, or only OR & NOT). This section teaches you how to manipulate Boolean expressions to fit these hardware limitations.

A. Using AND & NOT only

Rule: If you only have AND and NOT gates, you must eliminate all OR operations.
How? We use DeMorgan’s Law and the Double Complement rule (F = \overline{\overline{F}}).

Example from the lecture:
Given the function: F = (x \cdot y + \overline{x} \cdot \overline{y} + \overline{x} \cdot \overline{z})

1. Apply a double complement to the whole function: F = \overline{\overline{(x \cdot y + \overline{x} \cdot \overline{y} + \overline{x} \cdot \overline{z})}}
2. Use DeMorgan's Law on the bottom bar: The ORs (+) become ANDs (\cdot), and the variables get complemented.
3. Result: F = [(\overline{x} \cdot \overline{y}) \cdot (\overline{x} \cdot \overline{z}) \cdot (\overline{y} \cdot \overline{z})]

Diagram explanation (Page 5): The circuit is built purely using AND gates and NOT gates (inverters). The OR gate is completely eliminated.

B. Using OR & NOT only

Rule: If you only have OR and NOT gates, you must eliminate all AND operations.
How? Again, use DeMorgan’s Law and Double Complement.

Example from the lecture (Page 6):
Given: F = x\overline{y} + xz\overline{y} + yz

1. Double complement: F = \overline{\overline{(x\overline{y} + xz\overline{y} + yz)}}
2. Apply DeMorgan's: The ORs become ANDs, and the whole expression is complemented.
3. Break down the terms: F = \overline{(\overline{x} + y) \cdot (\overline{x} + \overline{z} + y) \cdot (\overline{y} + \overline{z})}

2. Complement of a Function

Finding the complement (the inverse) of a function is crucial. The complement of F is denoted as \overline{F} or F'.

The DeMorgan's Law Cases:

· Case ①: F = (A + B + C + D + \dots)
  · \overline{F} = \overline{(A + B + C + D + \dots)}
  · \overline{F} = \overline{A} \cdot \overline{B} \cdot \overline{C} \cdot \overline{D} \dots (OR becomes AND, variables complement).
· Case ②: F = (A \cdot B \cdot C \cdot D \cdot \dots)
  · \overline{F} = \overline{(A \cdot B \cdot C \cdot D \cdot \dots)}
  · \overline{F} = \overline{A} + \overline{B} + \overline{C} + \overline{D} + \dots (AND becomes OR, variables complement).

Example 3 (Page 8 & 9):

Find the complement of the following functions:
A) F_1 = \overline{x}y\overline{z} + \overline{x}\overline{y}z

· \overline{F_1} = \overline{(\overline{x}y\overline{z} + \overline{x}\overline{y}z)}
· Apply DeMorgan's: (\overline{x}y\overline{z})' \cdot (\overline{x}\overline{y}z)'
· Distribute the complement inside: (x + \overline{y} + z) \cdot (x + y + \overline{z})

B) F_2 = x(y\overline{z} + yz)

· \overline{F_2} = [x(y\overline{z} + yz)]'
· DeMorgan's on the outer bracket: \overline{x} + (y\overline{z} + yz)'
· DeMorgan's on the inner bracket: \overline{x} + (y\overline{z})' \cdot (yz)'
· Distribute: \overline{x} + (y + z) \cdot (\overline{y} + \overline{z})
· Multiply out: \overline{x} + y\overline{y} + y\overline{z} + z\overline{y} + z\overline{z}
· Since y\overline{y} = 0 and z\overline{z} = 0, they vanish.
· Final Answer: \overline{F_2} = \overline{x} + y\overline{z} + \overline{y}z

3. Express Functions in Canonical Form

Canonical forms are standard ways of writing Boolean functions. They are essential for designing circuits systematically and for programming logic arrays (like PLDs).

1. Sum of Minterms (SOP - Sum of Products)

A minterm (m) is an AND term that contains all variables of the function, either complemented or uncomplemented.

· For a 3-variable function (x, y, z), there are 8 minterms (m_0 to m_7).
· We write the function as the sum (OR) of the minterms where the function output is 1.
· Notation: F = \sum (m_1, m_4, m_5, m_6, m_7) or F = m_1 + m_4 + m_5 + m_6 + m_7

2. Product of Maxterms (POS - Product of Sums)

A maxterm (M) is an OR term that contains all variables.

· Maxterms are the opposite of minterms. M_i = \overline{m_i}.
· We write the function as the product (AND) of the maxterms where the function output is 0.
· Notation: F = \prod (M_0, M_2, M_3)

How to convert an expression to Sum of Minterms (Two Methods):

Method 1: Using the Truth Table
Example from Page 17: F = A + \overline{B}C

1. Create a table with columns for A, B, C.
2. Create a column for \overline{B}, and a column for \overline{B}C.
3. Calculate the output F = A + \overline{B}C for all 8 combinations (000 to 111).
   · If A=1, F=1.
   · If A=0, F depends on \overline{B}C. If B=0 and C=1, then \overline{B}C = 1 \cdot 1 = 1, so F=1.
4. Look at where F=1. These correspond to minterms m_1, m_4, m_5, m_6, m_7.
5. The Maxterms are where F=0: M_0, M_2, M_3.

Method 2: Using Equations (Algebraic Expansion)
Example from Page 19: F = xy + \overline{x}z
To find the minterms algebraically, you must multiply each term by (Variable + \overline{Variable}) to introduce the missing variables.

1. F = xy(1) + \overline{x}z(1)
2. F = xy(z + \overline{z}) + \overline{x}z(y + \overline{y})
3. Expand: xyz + xy\overline{z} + \overline{x}zy + \overline{x}z\overline{y}
4. Now every term has all 3 variables. Write their binary values:
   · xyz \rightarrow 111 \rightarrow m_7
   · xy\overline{z} \rightarrow 110 \rightarrow m_6
   · \overline{x}yz \rightarrow 011 \rightarrow m_3
   · \overline{x}\overline{y}z \rightarrow 001 \rightarrow m_1
5. F = m_1 + m_3 + m_6 + m_7 = \sum(1,3,6,7)
   (Note: The slide shows a different example F = xy + \overline{x}\overline{z} which leads to m_1, m_3, m_6, m_7 after a similar expansion).

How to convert to Product of Maxterms:

Example from Page 23: F = xy + \overline{x}\overline{z}

1. Factor out using the distributive law: (xy + \overline{x})(xy + \overline{z})
2. Further distribute: (x + \overline{x})(y + \overline{x}) \cdot (x + \overline{z})(y + \overline{z})
3. Since (x + \overline{x}) = 1, we are left with:
   F = (\overline{x} + y)(x + \overline{z})(y + \overline{z})
4. Now add the missing variables to each OR term by multiplying by (Var \cdot \overline{Var}), which is 0. Adding 0 doesn't change the function.

· (\overline{x} + y) + z\overline{z} = (\overline{x} + y + z)(\overline{x} + y + \overline{z})
   · (x + \overline{z}) + y\overline{y} = (x + y + \overline{z})(x + \overline{y} + \overline{z})
   · (y + \overline{z}) + x\overline{x} = (x + y + \overline{z})(\overline{x} + y + \overline{z})
5. Combine and remove duplicates: 
   F = (x+y+\overline{z})(x+\overline{y}+\overline{z})(\overline{x}+y+z)(\overline{x}+y+\overline{z})
6. Convert to Maxterm notation:
   · x+y+\overline{z} \rightarrow 110 \rightarrow M_6 (Wait, slide shows M_6 as x+\overline{y}+z. Let's look at the binary: 0 means uncomplemented, 1 means complemented. So x=0, y=0, z=1 \rightarrow M_1.
   · Let's check slide 24: M_4 = \overline{x}+y+z (100). M_5 = \overline{x}+y+\overline{z} (101). M_0 = x+y+z (000). M_2 = x+\overline{y}+z (010).
   · Result: F = M_0 \cdot M_2 \cdot M_4 \cdot M_5 = \prod(0, 2, 4, 5).
7. The corresponding minterms are the missing numbers: F = \sum(1, 3, 6, 7).

💡 Summary of Key Takeaways

· DeMorgan's Law is your best friend for changing operators (AND to OR, OR to AND) while flipping the individual variables.
· Double Complement (F = \overline{\overline{F}}) allows you to manipulate the entire function without changing its logic.
· Minterms (SOP) are based on the rows where the output is 1. You find them by multiplying by (V + \overline{V}).
· Maxterms (POS) are based on the rows where the output is 0. You find them by adding (V \cdot \overline{V}) and using distributive laws.
